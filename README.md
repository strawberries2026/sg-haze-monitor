# SG Haze Monitor

Independent personal project by Desmond Song providing Singapore regional 24-hour PSI and 1-hour PM2.5 information using official public data. Not affiliated with or endorsed by NEA or the Singapore Government.

Live website: https://strawberries2026.github.io/sg-haze-monitor/
